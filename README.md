# ¡Salvemos los Libros de Astronomía! - Instituto Cuatrovientos

Este proyecto es una Single Page Application (SPA) responsive desarrollada para el Instituto Cuatrovientos con el objetivo de catalogar, donar e intercambiar libros de astronomía y divulgación científica.

## 🚀 Características
- **Páginas / Vistas:** Inicio (Libros destacados), Actividades (Tabla responsive y filtros DOM), Contacto y Registro con validación HTML5.
- **Tecnologías:** HTML5, CSS3, Bootstrap 5.3, JavaScript Nativo (Manipulación del DOM).
- **Despliegue:** Optimizado para publicar en GitHub Pages.

## 📁 Estructura del proyecto
- `index.html`: Documento principal de la SPA.
- `README.md`: Documentación y guía del proyecto.

## 🛠️ Instrucciones de uso
Simplemente abre el archivo `index.html` en cualquier navegador web moderno o sirve la carpeta en tu servidor preferido.
